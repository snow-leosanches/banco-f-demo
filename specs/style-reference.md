## Typography

Real site uses a proprietary variable font (`mainFonts`, Arial fallback). Stand-in: **Figtree** (single family, like the real site).

- Headings: 500 weight, tracking -0.02em. Hero 40px / 56px line-height.
- Section titles (Gennial): 32px / 450.
- Body: 16px / 450.
- Nav: 14px / 600, `#585D61`.
- Utility: 13px / 500.
- Footer column titles: 16px, uppercase, 2px letter-spacing, `#C9D4DF`.

## Shape

- Marketing CTAs: **56px pills**, radius 128px, `#3B9326`.
- Header buttons: **40px pills**.
- Banners / opening cards: **24px** radius.
- Benefit promo tiles: **16px** radius, ~395×456.
- Inputs: **8px** radius, 54px height.
- Cookie notice: 16px radius, 72px, soft shadow.

## Layout

Three-tier sticky header → 1248px hero carousel → mint credit simulator → gray Gennial opening cards → daily benefits → Mantente al día → charcoal footer.
